# v0.2.1 (tagged, GitHub Release not published)

To update: Settings > Plugins > Add Plugin with `https://github.com/meryzennn/orca-discord-rpc.git#v0.2.1`, and review the commit Orca resolves. Plugin code is the same as v0.2.0.

## Added

- Four screenshots in the plugin manifest, so Orca's plugin page shows them. They are illustrations, not captures from a live session.
- A Preview section in the README with the same images.
- `src/manifest-assets.test.ts` checks that every screenshot stays inside Orca's image limits, because an image outside them makes the plugin impossible to install.

## Known issues

- One illustration (`docs/images/features.jpg`) says "About 53 KB". The bundle is now about 63 KB.
- The screenshots were stretched from 16:9 to 16:10 to meet Orca's 1280x800 minimum, so text looks slightly tall.
