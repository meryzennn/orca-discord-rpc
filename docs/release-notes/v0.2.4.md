# v0.2.4 (tagged, GitHub Release not published)

To update: Settings > Plugins > Add Plugin with `https://github.com/meryzennn/orca-discord-rpc.git#v0.2.4`, and review the commit Orca resolves. Remove or disable any development copy before enabling the Git installation.

## Fixed

- Playing Orca keeps its original elapsed timestamp when no workspace or agent is open. Version 0.2.3 kept the clock internally but dropped it from empty activity payloads, interrupting the visible timer.
- Project, agent, model, artwork and repository details stay hidden in the empty view; the timer continues across workspace and agent changes, Incognito toggles and reconnects.
- Push logs omit `art=none` when no large artwork reference is sent. Actual artwork references remain available for diagnostics.

Updating or restarting the plugin starts a new session. Pausing RPC or closing Orca also ends the current session; this change does not restore elapsed time from a previous worker.

## Verification

- Regression tests check the timestamps received by a local IPC peer across rich, empty-workspace, empty-agent and restored views for both plugin and daemon layouts.
- Session tests cover clock continuity, privacy, reconnect and pause/resume behavior.
