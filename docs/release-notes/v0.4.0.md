# v0.4.0

To update, add `https://github.com/meryzennn/orca-discord-rpc.git#v0.4.0` in Settings > Plugins > Add Plugin. The same Git plugin can be replaced without uninstalling it first. On Orca 1.4.253+, the update command can also install this release.

## Changed

- **Global Open Agent & Workspace Counts**: Presence now counts all open agents and all workspaces containing open agents across Orca, regardless of whether they are working or idle.
- **Card Line 1 Layout**: Line 1 now displays the featured agent name, total open agent count, and the featured agent's current status:
  `[Agent] · [N] agents · [Working/Idle]` (e.g. `Antigravity · 2 agents · Working` or `Antigravity · 1 agent · Idle`).
- **Card Line 2 Layout**: Line 2 displays the folder name and the workspace count:
  `📁 [Folder] · [N] workspaces` (e.g. `📁 orca-discord-rpc · 1 workspace` or `📁 orca-discord-rpc · 2 workspaces`).
- Removed the old `+N` agent suffix and standalone status labels.
- Preserves Incognito privacy, model hover tooltips, and Git repository buttons.

## Verification

- All 281 automated unit and integration tests passing.
- TypeScript typecheck passing with zero errors.
- Clean runtime build with zero npm runtime dependencies.
