# v0.4.1

To update, add `https://github.com/meryzennn/orca-discord-rpc.git#v0.4.1` in Settings > Plugins > Add Plugin. The same Git plugin can be replaced without uninstalling it first. On Orca 1.4.253+, the update command can also install this release.

## Fixed

- **Transparent Claude Artwork**: Replaced the solid-white Google favicon fallback for Claude and Claude Agent Teams with a transparent PNG logo. Resolves the white circle background when rendered in Discord's circular small-artwork slot.
