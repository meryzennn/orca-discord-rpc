# v0.3.1 (tagged, GitHub Release not published)

To update, add `https://github.com/meryzennn/orca-discord-rpc.git#v0.3.1` in Settings > Plugins > Add Plugin. The same Git plugin can be replaced without uninstalling it first. On Orca 1.4.253+, the update command can also install this release.

## Changed

- Removed the Update RPC button and its progress indicators from the bottom status bar. Only RPC and Incognito remain there.
- Update from Settings > Plugins > Discord Rich Presence: find **Discord RPC: Update installed plugin** and click **Run**. The command is also available in the command palette.
- Update requests immediately acknowledge that checking has started. Progress, installed/current versions, pinned versions and errors are reported in **Logs** on the plugin page.
- Duplicate clicks still share the active request, and completed or failed requests no longer publish late results after shutdown.

The updater still requires the **Orca application 1.4.253+**. Moving the control does not add updater support to older Orca versions. Installing an update restarts the worker and begins a new timer session.

## Verification

- Regression tests check that the update command remains registered while the manifest and runtime expose only the two presence/privacy status controls.
- Plugin lifecycle and headless updater tests cover result reporting, duplicate requests, shutdown and unchanged update behavior.
