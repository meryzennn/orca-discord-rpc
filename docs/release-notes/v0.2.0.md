# v0.2.0 (draft, not published)

To update: Settings > Plugins > Add Plugin with `https://github.com/meryzennn/orca-discord-rpc.git#v0.2.0`, and review the commit Orca resolves.

## Added

- Agent registry (`config/agents.json`): names, artwork, and model lookup for each Orca agent id, bundled into the plugin.
- `agents` map in `config.json` to name an agent, give it an icon, or pick its model lookup. Fields merge over the built-in entry.
- Unknown agent ids need no code change: generated name (`new-agent` becomes `New Agent`), the Orca icon, and the name as tooltip. Logged once per id.
- `📁` before the folder on line 2.
- Malformed `config.json` is reported in the plugin logs (and `daemon.log`) instead of being ignored silently.

## Changed

- Line 1 is `<Agent> · <Working|Idle>` with `+N` after the name for other open panes. The `Agent:` and `Folder:` labels are gone.
- Incognito shows `📁 Private Project`.
- The icon tooltip is the model, else the plain agent name (it was `Agent: <name>`).
- The headless daemon now uses the same text as the plugin (it previously showed `Claude +1` / `folder · Working`). Its icon layout is unchanged.
- Text is cut at grapheme boundaries, so emoji and flag sequences are never split.
- Model lookup is split into one module per agent. Behavior is unchanged.
- Agents without artwork (for example `qwen-code`) now get the Orca icon instead of no icon.
- The `agy` id is now shown as `Antigravity` (it was `Agy`).
- The bundle grew from about 55 KB to about 63 KB.

## Validation

- Automated: unit and integration tests, typecheck, plugin bundle build and isolated import (Windows, macOS, Linux CI matrix).
- Not verified: rendering in Discord desktop and mobile (emoji, truncation, tooltips, the Orca fallback favicon), and a real Orca install of the plugin. See the manual acceptance list in [DEVELOPMENT.md](../DEVELOPMENT.md#manual-acceptance).

## Migration

- Windows exe users (v0.1.9 and earlier): quit the app, run `OrcaPresence.exe autostart disable`, delete the folder, then install the plugin. Your `config.json` carries over. `setx ORCA_DISCORD_*` overrides no longer work; move them into `config.json`. See the README section "Migrating from the Windows exe".
- Plugin users on `#main`: add the plugin again with the tag URL above to pin this release.
- Headless daemon users: `git pull`, `npm ci`, `npm stop`, `npm start`. The daemon's text changes to match the plugin.
- Publishing note: the old Windows exe polls the latest release and tries to download `OrcaPresence-windows.zip`. See "Releases" in DEVELOPMENT.md before marking this release as latest.
