# v0.4.2

To update, add `https://github.com/meryzennn/orca-discord-rpc.git#v0.4.2` in Settings > Plugins > Add Plugin. The same Git plugin can be replaced without uninstalling it first. On Orca 1.4.253+, the update command can also install this release.

## Fixed

- **Ignore Sleeping & Archived Workspaces**: Workspaces that are sleeping or inactive (`status: "inactive"`, `terminalVerdict: "none"`, `hasAttachedPty: false` with `liveTerminalCount: 0`, or `isArchived: true`) and agent rows with `hasLivePty: false` are now excluded from both selected-workspace presence and global agent/workspace totals.
- Selecting a sleeping workspace now falls back to bare **Playing Orca** with its continuing elapsed timer instead of surfacing stale persisted agents.

## Verification

- 284 / 284 unit and integration tests passing (`npm test`), including regression coverage for sleeping and archived workspaces.
- TypeScript typecheck, plugin bundle build, and diff checks clean.
