# v0.2.3 (tagged, GitHub Release not published)

To update: Settings > Plugins > Add Plugin with `https://github.com/meryzennn/orca-discord-rpc.git#v0.2.3`, and review the commit Orca resolves. If you tested a development folder, remove or disable it before enabling the Git installation so only one presence provider runs.

## Fixed

- Discord keeps Playing Orca visible while Orca is open, even when no workspace is active.
- A workspace without an open agent shows the same bare activity, with no project, model, custom artwork, repository button or elapsed timer.
- Empty activity updates no longer require a timestamp. Both the plugin and headless daemon use this behavior.

## Behavior

- Opening an agent restores its details. An agent that is between turns keeps its Idle status.
- The session clock continues internally through empty views and reappears when an agent opens.
- Pausing RPC, disabling the plugin or closing Orca still removes the activity.

## Validation

- 257 automated tests, TypeScript checking and the plugin build pass.
- Discord desktop acknowledged bare activity payloads from both builders and an explicit clear.
- Local manual testing was confirmed before release.

## Known issues

- Empty activity views omit the elapsed timestamp, interrupting the visible timer. This is fixed in v0.2.4.
- The existing feature illustration says "About 53 KB" and does not reflect the current bundle size.
- Existing illustrations were stretched from 16:9 to 16:10, so text looks slightly tall.
